# Backend - DinoKing Games

This is the backend API for the DinoKing Games project, providing authentication and game management services.

## Structure

```
backend/
├── api.php                      # Main API entry point
├── .htaccess                    # Apache rewrite rules
├── app/                         # Application code
│   ├── Controllers/             # Controllers for API endpoints
│   │   ├── api/
│   │   │   ├── AuthController.php   # Authentication endpoints
│   │   │   └── AdminController.php  # Admin management endpoints
│   │   ├── DinosaurioController.php # Game dinosaur logic
│   │   └── JuegoControlador.php     # Game controller
│   ├── Repositories/            # Data access layer
│   │   ├── UsuarioRepository.php
│   │   ├── EstadoPartidaRepository.php
│   │   └── DinoModels.php
│   ├── config/                  # Configuration files
│   │   ├── app.php              # Application paths
│   │   └── database.php         # Database connection
│   ├── Core/                    # Core functionality
│   │   └── router.php           # Router (not used in API mode)
│   └── Database/                # Database setup
│       ├── schema.sql           # Database schema
│       └── triggers_superadmin.sql  # Database triggers
└── README.md                    # This file
```

## API Endpoints

### Health Check
- `GET /health` - Check API status

### Authentication
- `GET /session` - Get current session info
- `POST /auth/register` - Register new user
- `POST /auth/login` - Login user
- `POST /auth/logout` - Logout user

### Admin (requires admin/superadmin role)
- `GET /admin/users` - List all users
- `GET /admin/get_user?id={id}` - Get specific user
- `POST /admin/delete_user` - Delete user
- `GET /admin/get_roles` - Get available roles
- `GET /admin/get_role_history` - Get role change history
- `POST /admin/update_role` - Update user role

## Setup

1. **Database Configuration**
   
   Edit `app/config/database.php` with your database credentials:
   ```php
   DB_HOST='127.0.0.1'
   DB_PORT='3306'
   DB_NAME='dinoking_database'
   DB_USER='root'
   DB_PASS='your_password'
   ```

2. **Database Setup**
   
   Run the SQL files to set up the database:
   ```bash
   mysql -u root -p < app/Database/schema.sql
   mysql -u root -p < app/Database/triggers_superadmin.sql
   ```

3. **Run the Server**
   
   For development:
   ```bash
   # From project root
   php -S localhost:8000 -t .
   ```
   
   The API will be available at: `http://localhost:8000/backend/api.php`

## Requirements

- PHP 8.0 or higher
- MySQL 5.7+ or MySQL 8.0+
- mysqli extension enabled
- Apache (with mod_rewrite) or PHP built-in server

## Security

- Session cookies are configured with httponly, secure, and samesite flags
- All API responses use JSON format
- Input validation is performed on all endpoints
- Database queries use parameterized statements

## Notes

- This backend is designed to be completely separate from the frontend
- No HTML is generated by the backend
- All responses are in JSON format
- CORS headers may need to be configured for production deployment
